# Sawdagar category visuals

These transparent category assets were created as a matched, original set with the built-in ImageGen tool. The 1254 px masters remain in the local generated-images store; the app and admin receive optimized 360 px PNGs.

## Shared generation prompt

Use case: premium mobile e-commerce category icon. Create an advanced photorealistic high-end Blender/Cinema 4D product visualization with physically based rendering, accurate proportions, true-to-life materials, and premium 2026 commerce-app quality. Use one compact centered object group in a three-quarter front view, filling about 76% of a square canvas with safe padding. Use professional softbox lighting, a restrained rim light, a realistic contact shadow, and a genuinely transparent outer background. Use natural materials with a restrained Sawdagar cobalt-blue accent (`#2D50D5`). Keep clean alpha edges and a strong silhouette readable at 64 px. Do not include a circle, tile, badge, border, text, label, price, brand, logo, or watermark. Avoid cartoon, clay, vector, emoji, fake-plastic, excessively glossy, cluttered, duplicated, or deformed results.
